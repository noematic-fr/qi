**Victoire :** tous les moutons dans le parc **et** portail fermé.

### Conseils

#### Approchez par derrière

Les moutons fuient le chien. Arrivez derrière le troupeau pour le pousser vers le parc plutôt que de le disperser.

#### Discipline du portail

Ouvrez pour faire entrer les moutons, puis **fermez** pour valider. Un portail ouvert invite les fuites.

#### Des étoiles, pas de punition

Pas d’échec chronométré dur — prenez votre temps si besoin. Les runs rapides rapportent plus d’étoiles.
