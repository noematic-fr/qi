### Conseils

#### Larguer l’eau face au vent

La vitesse de l’avion et le vent dispersent l’eau. Pour plus de précision, volez et larguez **face au vent** pour atteindre le feu.

#### Essence et lacs

Surveillez le réservoir. Atterrissez sur la piste pour faire le plein d’essence ; rasez les lacs pour remplir l’eau.

Non. L’embed ci-dessus est le **classique 2013** (Impact.js). Le **remaster Godot** est un achat desktop séparé sur [Payhip](https://payhip.com/b/boOuR).

Oui — classique et remaster proposent des cartes procédurales pour des défis toujours différents.

#### Allez-vous remplacer le classique gratuit par Godot dans le navigateur ?

Pas tout de suite. Le classique reste gratuit en ligne. Un export web du remaster pourra venir plus tard ; tout remplacement d’embed attend le retour joueurs après la sortie desktop.

#### Et Fire Command ?

Fire Command est un jeu séparé dans le même univers (couche commandement). Il n’est pas inclus avec Air Fireman.

#### Seulement macOS / Windows ?

Les premiers builds remaster sont **macOS** et **Windows**. Linux pourra suivre. Le mobile reste le classique web pour l’instant.
